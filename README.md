## WELCOME TO MY PROJECT FASHION APP

### Introduction

This is my next project about an online clothing store where this store has many categories of clothes that are sold at affordable prices and full of discounts.

The flow of the program is simple, you only need to log in, find the product you want to buy, enter the checkout process, pay with the available payment methods and then the receipt number will be available to track the item.

This program is made with designs that I searched from dribbble or other reference design sites.

### Requirements

I assume you are familiar with javascript and typescript and modern frameworks.

- Javascript & Typescript
- Node js v20^
- Vue js 3 + Pinia + Some plugin for development
- TailwindCss
- Shadcn vue version
- Swipper js

You need all of that to run the program, if you feel incomplete please see the package.json section

### Step by step

- Pull this repository
- npm install
- npm run dev
